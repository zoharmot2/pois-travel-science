## Stage 12 purpose

Stage 12 is the final functional/browser regression gate for v1.4 before documentation cleanup and release preparation.

It validates the same codebase in two presentation modes:

- Standalone mode — full site with header and complete application chrome.
- Embedded mode — `?embed=true` or `?embed=1`, with the header removed and compact layout behavior.

Each mode must be checked at desktop and narrow/mobile widths.

## Stage 12 additions

- `docs/regression-qa.md` is replaced by a v1.4-specific four-mode release matrix covering multi-geometry rendering, unified filtering, multi-result search, Detail Panel behavior, media, utilities, and console errors.
- `TESTING.md` now points to the current v1.4 release-regression procedure instead of the older v1.3 matrix.
- `TESTING-v1.4-stage12.md` provides the short operational sequence for local validation.

## Important release rule

Automated static QA cannot prove visual layout or interactive browser behavior. Stage 12 remains open until the manual Standalone/Embedded × Desktop/Narrow matrix passes in the user's working repository.
