## Core rules

- ArcGIS Online / Field Maps is authoritative and must not be destabilized.
- Website UI is English-only.
- `GlobalID` is the canonical stable entity ID.
- `POI_Type` is the primary legend/symbology dimension.
- `POI_Topic` remains research metadata, not the primary map legend.
- POI Type values are extensible; live values across all datasets are unioned and unconfigured Types get fallback styling plus QA warning.
- Geometry visibility is a separate control: Points / Lines / Polygons.
- Attachments: images and audio are downloaded locally; unsupported media such as video remains a direct ArcGIS URL. Deleted AGOL entities/attachments remove corresponding local files after a successful refresh.
- Standalone and embedded modes share one codebase and must both remain supported.
